# Agent Instructions

## Project Background

Starbound is a space-based game built with Three.js, React, TypeScript, and Vite. The end goal is to create a fully playable, open-source game that can be played in a browser. This game takes inspiration from Star Wars Galaxies and No Man's Sky.
The player will be able to fly around the galaxy, explore planets, collect resources, and complete quests. There will be a small narrative as well as a progression system that should feel rewarding.
